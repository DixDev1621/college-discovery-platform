# College Discovery Platform

A modern college discovery platform built using Next.js, TypeScript and Tailwind CSS.

## Features

* College Listing
* Search Colleges
* Filter by Location
* Sort by Rating and Fees
* Pagination
* College Detail Page
* Compare Colleges
* College Predictor Tool
* Save Colleges
* Responsive Design

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
